# Capstone Project 1 – Online Resume

## Project Overview

**Capstone Project 1 – Online Resume** is a multi-page personal website designed to showcase a fictional professional resume using basic web development principles. The project demonstrates foundational skills in **HTML structure, semantic markup, navigation, and content organization**.

The website represents a fictional senior data analyst, *Jordan Ramirez*, and includes multiple interconnected pages such as a resume, about section, hobbies, achievements, and contact information. All content is created for **educational purposes only**.

---

## Project Objectives

The primary goals of this project are to:

* Apply core HTML concepts to build a structured website
* Create a professional-style online resume
* Implement consistent navigation across multiple pages
* Organize information using semantic HTML elements
* Demonstrate understanding of web page layout and linking
* Practice building a capstone-level project suitable for a portfolio

---

## Technologies Used

* **HTML5**

  * Semantic elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
  * Lists, images, links, and forms
* **No external libraries or frameworks**
* **No CSS or JavaScript** (can be added in future iterations)

## Page Descriptions

### 1. Resume Page (`index.html`)

* Displays the main professional resume
* Includes:

  * Professional summary
  * Education
  * Work experience
  * Skills
  * Awards and certifications
* Serves as the homepage of the website

### 2. About Me Page (`about.html`)

* Provides a personal and professional background
* Explains career interests and goals
* Introduces the purpose of the website

### 3. Hobbies and Interests Page (`hobbies.html`)

* Highlights personal interests outside of work
* Demonstrates balanced professional and personal development

### 4. Achievements and Projects Page (`achievements.html`)

* Lists certifications, awards, and recognitions
* Describes selected professional and academic projects

### 5. Contact Me Page (`contact.html`)

* Displays contact details (email, location, links)
* Includes a basic HTML contact form (non-functional)
